# Documentation Context Rule

Before implementing a new user story or making significant changes, always check the `GSoC_Notes/3_Documentation` folder first. 

This ensures you have a good understanding of what features have already been implemented, their current architecture, and any existing design decisions before you start writing new code.

# User Story Creation Rule

When asked to create new user stories:
- Always create them inside the `GSoC_Notes/1_UserStories` directory.
- Always base them on the template located at `GSoC_Notes/Templates/UserStoryTemplate.md`.
