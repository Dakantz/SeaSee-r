# User Story: 3D Map Construction (openFsM)

## Description
As an end-user, I want to feed curated keyframes and SLAM trajectory snippets into openFsM so that I can construct a dense, scaled 3D map of the ocean floor.

## Acceptance Criteria
- [ ] Feed the curated keyframes into the `openFsM` algorithm.
- [ ] Import the trajectory snippets generated by the SLAM pipeline as camera pose priors in `openFsM`.
- [ ] Construct the final dense 3D map of the ocean floor.
- [ ] Ensure the scale of the 3D map matches the real-world depth data.

## Technical Constraints / Notes
- Providing camera pose priors gives `openFsM` a massive head start, preventing it from failing during the sparse reconstruction phase.
- Ensure integration with `SeaSee-r/openFsM/openFsM_core/bin/import_video` if applicable.
- Test framework currently not setup, to be added later.
