# Performance Test: Native PointsMaterial Point Cloud Rendering

## Overview
This document records performance benchmarks for rendering 3D point clouds using standard Three.js `pointsMaterial` with vertex colors, point size, and size attenuation in `PLYPointCloud.tsx` and `DynamicCubicLODController.tsx`.

## Test Parameters
- **Test Target:** Point cloud rendering using standard `pointsMaterial`
- **Component Files:** `PLYPointCloud.tsx`, `DynamicCubicLODController.tsx`
- **Total Pointcloud pointcount\*:** `98,441,860 pts`
- **Target Duration:** 30 seconds
- **Start Camera Position:** `(10, -100, 10)`
- **End Camera Position:** `(10, 100, -10)`

\* Not all points are rendered simultaneously. Chunks are loaded dynamically based on camera distance Level-of-Detail (LOD).
